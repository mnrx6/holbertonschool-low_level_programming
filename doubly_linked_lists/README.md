# Doubly Linked Lists

This project covers the basics of doubly linked lists in C.

## Learning Objectives

- Understand doubly linked lists.
- Traverse a doubly linked list.
- Add nodes at the beginning and end.
- Insert and delete nodes at specific indexes.
- Get nodes by index.
- Calculate the sum of node values.
- Free allocated memory.

## Files

- `0-print_dlistint.c` - Prints all elements.
- `1-dlistint_len.c` - Returns the number of nodes.
- `2-add_dnodeint.c` - Adds a node at the beginning.
- `3-add_dnodeint_end.c` - Adds a node at the end.
- `4-free_dlistint.c` - Frees the list.
- `5-get_dnodeint.c` - Gets a node at a given index.
- `6-sum_dlistint.c` - Returns the sum of all node values.
- `7-insert_dnodeint.c` - Inserts a node at a given index.
- `8-delete_dnodeint.c` - Deletes a node at a given index.
- `lists.h` - Contains the structure and function prototypes.
