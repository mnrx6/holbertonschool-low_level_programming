# Variadic Functions

This project introduces variadic functions in C using the `stdarg.h` library.

## Files

* `0-sum_them_all.c` - Returns the sum of all arguments.
* `1-print_numbers.c` - Prints numbers.
* `2-print_strings.c` - Prints strings.
* `3-print_all.c` - Prints different data types.
* `variadic_functions.h` - Function prototypes.

## Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```
