# Hash Tables

This project covers hash tables in C.

## Learning Objectives

- Understand hash functions
- Understand hash tables
- Handle collisions using chaining
- Add and retrieve key/value pairs
- Print and delete a hash table

## Files

- `0-hash_table_create.c` - Creates a hash table
- `1-djb2.c` - Implements the djb2 hash function
- `2-key_index.c` - Gets the index of a key
- `3-hash_table_set.c` - Adds or updates an element
- `4-hash_table_get.c` - Retrieves a value by key
- `5-hash_table_print.c` - Prints a hash table
- `6-hash_table_delete.c` - Deletes a hash table
- `hash_tables.h` - Header file

## Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c
```
