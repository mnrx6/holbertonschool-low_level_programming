# Singly Linked Lists

This project covers the basics of singly linked lists in C.

## Learning Objectives

* Understand when to use linked lists instead of arrays.
* Understand how singly linked lists work.
* Traverse a linked list.
* Add nodes at the beginning and end of a list.
* Count and print nodes.
* Free allocated memory.

## Files

* `0-print_list.c` - Prints all elements of a linked list.
* `1-list_len.c` - Returns the number of nodes.
* `2-add_node.c` - Adds a node at the beginning.
* `3-add_node_end.c` - Adds a node at the end.
* `4-free_list.c` - Frees a linked list.
* `lists.h` - Contains the structure and function prototypes.
